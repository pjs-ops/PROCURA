
# PROCURA — Procurement Intelligence Platform

A modern procurement dashboard designed to simplify procurement analysis through interactive visualizations, supplier insights, spending analytics, and risk monitoring.

## Features

- **Overview Dashboard** — Centralized view of procurement information.
- **Spend Intelligence** — Visualize procurement spending patterns.
- **Supplier Management** — Explore supplier information and performance.
- **Purchase Orders** — View purchase order information.
- **Risk Radar** — Monitor procurement risk indicators.
- **Savings & Forecasting** — Explore savings and forecasting dashboards.
- **Contracts & Reports** — Access contract-related and reporting interfaces.
- **Digital Twin & AI Analyst** — Dedicated interfaces for advanced procurement insights.

*Note: The frontend currently uses mock data where applicable. No backend has been implemented yet.*

## Tech Stack

- React 19

- Vite

## Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/PROCURA.git
```

**2. Navigate to the frontend**

```bash
cd PROCURA/frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Build for production**

```bash
npm run build
```
